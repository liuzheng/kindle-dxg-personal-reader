# Physical-device blockers

The following cannot be resolved by a local-only project:

1. Safe debug console and a non-persistent boot route.
2. Full device-specific flash map, flash backup, and recovery rehearsal.
3. Exact i.MX31 variant, RAM timing, clocks, interrupts, and boot arguments.
4. E-Ink controller, waveform source, PMIC, touch/input controller, and their usable driver source.
5. USB role configuration and safe gadget validation.
6. Battery/charger and suspend/resume behavior.
7. Phase 2 DTP-600W slot control signals, power margin, physical mounting, and antenna routing.

Do not jailbreak or connect to the device to resolve these blockers without explicit approval for the physical-device phase.
